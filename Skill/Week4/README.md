# WEEK 4 – Tokenizer Lab

## 1. Aim

To understand and compare different tokenization techniques used in Natural Language Processing (NLP) by applying three tokenizers to English, Telugu, and Hindi text.

## 2. File Name

`Week4_Tokenizer_Lab.ipynb`

## 3. Description

This experiment demonstrates how different tokenizers divide sentences into smaller units called tokens.

The notebook uses the Hugging Face Transformers library to load and compare three tokenization methods:

1. **BPE – GPT-2:** Uses Byte Pair Encoding.
2. **WordPiece – Multilingual BERT:** Uses the WordPiece tokenization method.
3. **SentencePiece – XLM-R:** Uses SentencePiece tokenization.

The experiment processes sentences in three languages and displays their tokens, token IDs, and token counts.
